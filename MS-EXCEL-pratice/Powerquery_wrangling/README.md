# Power Query – Data Wrangling Practice

## Overview

This folder contains my Microsoft Excel Power Query practice.

Power Query is a data preparation tool used to import, clean, transform, and combine data from different sources. It helps automate repetitive data-cleaning tasks and prepare datasets for analysis.

## Objectives

* Learn the fundamentals of Power Query in Excel.
* Import data from different sources.
* Clean and transform raw datasets.
* Handle missing values, duplicates, and inconsistent data.
* Reshape data using Pivot and Unpivot.
* Combine datasets using Merge and Append.
* Build a repeatable data-cleaning workflow.

| No. | Topic                       | Description                                                  |
