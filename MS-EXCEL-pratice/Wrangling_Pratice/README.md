# Excel Data Wrangling Practice

## Overview

This folder contains my Microsoft Excel practice work focused on **data wrangling, data cleaning, and data preparation** 


## Objectives

* Understand the fundamentals of data wrangling in Excel.
* Learn to clean and organize spreadsheet data.
* Practise Excel lookup functions to retrieve related information.
* Handle formula errors and missing lookup results.
* Summarize data for analysis and reporting.
* Develop practical Excel skills for Data Analyst roles.

## Topics Covered

| No. | Topic                   | Description                                                     |
| --- | ----------------------- | --------------------------------------------------------------- |
| 1   | Data Cleaning           | Identify and correct inconsistent or incorrect data.            |
| 2   | Sorting and Filtering   | Arrange data and display records based on conditions.           |
| 3   | LOOKUP                  | Search for values and return corresponding results.             |
| 4   | VLOOKUP                 | Retrieve information from another column in a table.            |
| 5   | XLOOKUP                 | Perform flexible lookups with exact matching by default.        |
| 6   | IFERROR                 | Handle formula errors using alternative values or messages.     |
| 7   | Grouping and Ungrouping | Organize rows and columns into expandable groups.               |
| 8   | Subtotaling             | Calculate summaries such as sums and counts for groups of data. |

##  Learning Outcomes

Through this practice, I aim to:

* Improve my data-cleaning and preparation skills.
* Understand how lookup functions connect related datasets.
* Organize and summarize data efficiently.
* Build a foundation for more advanced Excel analysis.
* Apply these skills to real-world data analytics tasks.
