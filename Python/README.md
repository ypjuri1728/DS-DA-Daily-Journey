# Day 01 — Python Lists

## What is a List?

A list is a collection used to store multiple values
in a single variable.

## Example

numbers = [10, 20, 30, 40]

## Important things I learned

- Lists are ordered
- Lists are mutable
- Lists allow duplicate values
- Indexing starts from 0

## Methods

- append()
- remove()
- pop()
- sort()
- reverse()
